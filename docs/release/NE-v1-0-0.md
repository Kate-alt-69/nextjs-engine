# Next.js Engine v1.0.0 — Initial Public Release

> **Released:** 2026-06-06  
> **GitHub tag:** `release-v1-0-0`

v1.0.0 was the first public Next.js Engine release.

The original goal was to provide an Engine-managed layer for building fast Next.js sites without requiring every application author to hand-optimize every repeated layout/runtime concern.

---

## Original workflow

The v1.0.0 release documentation used the following build/start workflow:

```powershell
npm run clear
npm run build
npm run start
```

The original release also recommended PowerShell 7 for the Windows workflow:

```powershell
winget install --id Microsoft.PowerShell --source winget
```

At the time, the generated application output was intended to be deployable from the configured build output directory to static/web hosting providers.

---

## What v1.0.0 represents

v1.0.0 is the historical starting point for the Engine before the later v2 architecture introduced:

- EngineMobile server-side patching;
- EngineScroll;
- EngineBrowser;
- schema diagnostics;
- EngineAPI;
- the larger Canvas/graphics runtime;
- APIStatic;
- EngineShader;
- EngineTransitions+;
- EngineOverlay.

For current usage, always prefer the maintained docs rather than treating this old release workflow as current API guidance.
