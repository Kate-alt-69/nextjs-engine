## Tag naming

Historical tags are not perfectly consistent:

```text
release-v1-0-0
release-V2-0-0
Release-v2.5.0
```

For v2.6.0 the recommended tag is:

```text
Release-v2.6.0
```

That follows the most recent v2.5.0 convention.
