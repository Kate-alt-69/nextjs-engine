## Tag naming

Historical tags are not perfectly consistent:

```text
release-v1-0-0
release-V2-0-0
Release-v2.5.0
```

For the current v2.6 line the recommended tags are:

```text
Release-v2.6.0
Release-v2.6.1
Release-v2.6.2
```

That follows the most recent v2.5.0 convention.
