## APIStatic

APIStatic introduced build-time compilation for:

```text
data/endpoint/**/*.route
```

The system can:

- compile `.route` files into browser-loadable static endpoint modules;
- generate a route manifest automatically;
- use stable logical endpoint names without requiring application code to know generated hashes;
- support multiple operations per endpoint;
- support `run.query`, `run.body`, `run.input`, and `run.proxy`;
- validate and coerce typed input schemas;
- support defaults and optional values;
- use normal async functions, `fetch()`, objects, arrays, and TypeScript syntax;
- return normal values or explicit `response(...)`;
- throw controlled `error(...)` responses;
- call configured backend bridges through `proxy()`;
- discover endpoints with `APIStatic.names()`, `has()`, and `getEndpoints()`;
- watch and recompile `.route` files during development;
- preserve the last-known-good build when compilation fails;
- publish endpoint JavaScript and its manifest atomically;
- handle lexical scopes correctly;
- support compact `helper[...]` call syntax without corrupting normal arrays/strings/comments/regex/shadowed values;
- integrate directly with `EngineAPIResolver`;
- run dedicated compiler/runtime regression checks in CI.

## Runtime and graphics work

v2.5.0 also focused heavily on making previously documented runtime behavior match the actual implementation.

Major work included:

- demand-driven / more efficient Canvas and graphics execution;
- retained 2D/3D/SVG rendering improvements;
- EngineManim lifecycle and allocation reductions;
- EngineScroll scheduling and point navigation fixes;
- improved media loading and lazy behavior;
- EngineBrowser SSR hardening;
- schema/type/API corrections;
- bundle and package synchronization improvements.

---

## Build and package workflow

The release established stronger automated package behavior around the two main branches:

```text
main
	→ workspace/source branch

main-empty
	→ distributable package branch
```

The repository gained automated synchronization and stronger integration/build checks so package output could be verified rather than copied manually.
